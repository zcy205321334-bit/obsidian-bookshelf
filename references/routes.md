# 路由与阶段

| route | 基础输出 | 允许的进阶输出 | 属性 |
|---|---|---|---|
| `game` | `游戏库/游戏书架.md`、`游戏库/分类/未分类.md`、条目卡片 | 介绍、剧情、攻略、角色索引、角色页 | `platform`, `type`, `status` |
| `manga` | `漫画库/漫画书架.md`、`漫画库/分类/未分类.md`、条目卡片 | 剧情、角色索引、角色页 | `author`, `status`, `tags` |
| `photo` | `照片库/相册.md`、`照片库/时间轴.md`、条目卡片 | 无 | `time`, `event` |
| `course` | `课程库/课程总览.md`、条目卡片 | 无 | `course`, `source` |

## 进阶触发

游戏与漫画只允许：用户在盘点后以 `-AdvancedItem` 精确点名；或 `total_count <= 20` 且用户在盘点后明确说“按这个标准做”，同时传入 `-InventoryConfirmed -ApprovedSmallLibraryStandard`。不得把“都整理一下”“详细一点”等表达解释为触发。照片与课程即使传入上述参数也拒绝进阶集群。

## 基础布局

每个路由写入独立根目录，条目位于 `条目/`。MOC 与分类/时间轴使用 wikilink 指向条目卡片。若 vault 根已有 `HOME.md`，只更新其中受管区块；若不存在则完全不创建。

## 进阶布局

进阶页面放在 `条目/<安全条目名>/`。游戏生成介绍、剧情、攻略、角色索引；漫画生成剧情、角色索引。没有用户提供的角色资料时不虚构角色页；只有明确提供角色名时才从角色页模板生成。
